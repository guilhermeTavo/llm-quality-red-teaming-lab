# Landing Page Design Audit

This audit documents the anti-AI-slop review used before redesigning the project landing page.

## Audit Goal

The goal is to avoid a landing page that looks like a default AI-generated SaaS template.

The page should support the credibility of the project: a practical LLM evaluation and red teaming lab built for an AI Quality / QA portfolio.

## Issues Found in the Previous Landing Page

| Area | Finding | Risk | Action |
|---|---|---|---|
| Dark AI SaaS look | The page used a dark blue/cyan visual style. | Looks common among AI-generated websites. | Move to a light editorial report style. |
| Hero structure | The page used a predictable hero with badge, large heading, subtitle and buttons. | Feels template-based. | Replace with asymmetric research-brief header. |
| Badge above H1 | A pill label appeared directly above the main headline. | Common AI landing-page pattern. | Remove badge and use structured metadata instead. |
| Card grid | Evaluation areas were shown as six similar cards. | Generic feature-grid pattern. | Replace with a ledger/table-like inspection layout. |
| Numbered process section | Workflow used numbered visual steps. | Common AI-generated process pattern. | Use report-style method notes instead. |
| Glow and dark panels | Cards relied on dark panels, cyan accent and shadow. | Overused AI/SaaS aesthetic. | Use paper, ink, sand and restrained accent tokens. |
| CTAs | Buttons were visually prominent in a generic way. | Looks like a product landing page rather than a portfolio report. | Use smaller, document-like links. |
| Footer | Footer was acceptable but still conventional. | Low risk. | Keep only real links and concise author information. |

## Anti-Slop Checks Applied

The redesign avoids:

- indigo-to-purple gradients;
- Inter/Roboto-first visual identity;
- tiny uppercase eyebrow labels above the hero;
- badge directly above the H1;
- centered hero layout;
- glassmorphism with neon glow;
- identical feature-grid cards;
- emoji icons;
- fake client marquees;
- fake testimonials;
- generic abstract illustrations;
- dead footer links;
- fake product screenshots;
- invented metrics.

## Honest Metrics Check

The landing page uses only numbers that already exist in the project files:

- 20 sample test cases executed;
- 10 quality tests;
- 10 red-team tests;
- 100% sample safety pass rate.

These are clearly presented as a **manual sample run**, not as an official benchmark.

## Redesign Direction

The redesigned page should feel like:

- a QA field report;
- an evaluation dossier;
- a technical case study;
- a portfolio artifact for recruiters.

The design should prioritize evidence, methodology and readability instead of generic marketing polish.
