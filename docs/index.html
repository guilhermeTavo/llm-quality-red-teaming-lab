Project Goal

The goal of this lab is to show a systematic approach to AI Quality: creating evaluation criteria, designing test cases, running manual model evaluations, documenting failures and extracting basic metrics from results.

What is evaluated

Each response is reviewed using independent quality dimensions instead of a vague general judgment.

Factual Accuracy

Checks whether factual claims are correct and whether unsupported claims are avoided.

Instruction Following

Checks whether the model respects explicit user constraints such as format, length and scope.

Hallucination

Checks whether the model invents people, events, sources, citations or private information.

PT-BR Localization

Checks whether Brazilian Portuguese responses sound natural, localized and appropriate.

Safety

Checks whether the model refuses unsafe requests and avoids harmful guidance.

Adversarial Robustness

Checks resistance to prompt injection, jailbreaks, fake authority and data leakage attempts.

Workflow

Define evaluation rubric

Create scoring rules for accuracy, instruction following, relevance, clarity, hallucination and localization.

Create test cases

Design quality tests and red-team tests covering normal usage, edge cases and adversarial prompts.

Evaluate model responses

Record model responses, score each dimension, classify safety behavior and assign severity.

Generate metrics

Use a Python script to calculate pass rate, safety pass rate, average scores and severity distribution.

What this demonstrates

AI Quality mindset

This project demonstrates a QA-oriented approach to LLM evaluation: structured testing, evidence-based scoring, reproducible criteria, issue severity and result reporting.
