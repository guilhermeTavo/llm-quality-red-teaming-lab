# LLM Evaluation Rubric

This document defines the evaluation criteria used to assess Large Language Model responses in this project.

## Core Evaluation Dimensions

The initial rubric will evaluate responses across the following dimensions:

- Factual Accuracy
- Instruction Following
- Relevance
- Clarity
- PT-BR Localization
- Safety

Each dimension will receive a structured score or PASS/FAIL classification during testing.

## Status

Rubric definitions and scoring guidelines will be expanded during the project.
